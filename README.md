# Nataliia Hirniak — Portfolio

Personal portfolio website built with React, TypeScript, and Tailwind CSS.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** — build tool
- **Tailwind CSS v4** — styling
- **Zod** — form validation
- **EmailJS** — contact form
- **Sonner** — toast notifications
- **Lucide React** — icons
